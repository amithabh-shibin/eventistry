EVENTISTRY STATIC WEBSITE

Open the website
1. Extract the whole ZIP into one folder.
2. Double-click index.html to open the homepage.
3. Open the HTML files in VS Code to edit them.

Publish the website
Upload the extracted files and folders together to the root of your static
web host. Keep index.html beside the assets, css and js folders. No Node.js
installation or build command is needed.

Pages and assets
index.html, about.html, services.html, gallery.html, contact.html,
event-decoration-dubai.html and privacy.html sit in the website root.
Shared styling is in css/styles.css. Frontend code is in js/. Photos and
logos are in assets/.

Quotation enquiries
The forms assemble a message and open Eventistry's WhatsApp chat. The
visitor sends the message and can attach reference photos in the chat.
This static edition has no built-in admin panel or enquiry database.
Update content, prices and photos directly in the website files.

SEO
Each page has a title and description. robots.txt allows crawling. Once
you have a domain, replace YOUR-DOMAIN.example in sitemap.xml.example
and save it as sitemap.xml at the site root.
